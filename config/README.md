# config の運用

## owners.json（苗字で振れるシステム）

## 仕組み

- **ownerAliases**: `苗字 or 短い名前 → フルネーム`（1対1）。ここにいれば Slack で「中村」「浦本」のように書くだけで担当が振られる。
- **ambiguousFamilyNames**: `苗字 → [フルネーム1, フルネーム2, ...]`（同姓が複数いる場合のみ）。ここに書いた苗字**だけ**で指定されると、**必ず聞き返す**（タスクは作らない）。

例: 石原が2人（石原采音・石原舞）いるので、`"石原": ["石原采音", "石原舞"]` を入れてある。「石原」とだけ書いたときは「どちらに振りますか？」と返し、「石原采音」または「石原舞」と書けばその人に振られる。

## メンバーが増えたとき

1. **ownerAliases** に `"苗字": "フルネーム"` を1行追加する。
2. 同じ苗字の人が**すでに ownerAliases にいる**場合だけ、**ambiguousFamilyNames** にその苗字を追加する。
   - 例: 新しく「石原翔太」が入った → `ambiguousFamilyNames` の `"石原"` を `["石原采音", "石原舞", "石原翔太"]` に更新。
3. リマインドでメンションするなら **ownerToSlackId** に `"フルネーム": "U01234..."` を追加。

これで「苗字で指示されても適用される」仕組みがメンバー追加後もそのまま動く。

## プロジェクトの指定

Slack でタスク作成時に、`#プロジェクト名` を付けるとその Todoist プロジェクトに追加される。

- 例: `/todoist 逆転転職meta運用 明日 浦本 #逆転転職`
- プロジェクト名は Todoist のプロジェクト名と一致（または部分一致）すること。API から自動で照合する。
- 省略すると Inbox に入る。
